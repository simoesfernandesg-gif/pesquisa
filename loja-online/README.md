# Terceiro Projeto - Loja online

Este é um projeto desenvolvido com a linguagem Python, para calcular descontos a partir de determinadas condições.
Compras acima de R$ 300 desconto de 15%, maior ou igual a R$ 200 desconto de 10% e
menor que R$ 200 deconto de 5%, utilizando a fórmula: desconto = (valor_compra*15)/100 - ex usado para calcular 15%.
O programa pede ao usuário para digitar o valor da compra.
