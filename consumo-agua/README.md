# Conscientização do uso da água 🤔

Este programa tem como objetivo informar à população qual o perfil de cada residência
de acordo com o consumo mensal e do tipo de imóvel.

## Como Funciona ?

1. O programa solicita que o usuário informe o **tipo de imóvel**. 🏠 
2. Em seguida, pede a digitação do **consumo mensal de água** em metros cúbicos (m³). 
3. A partir dos dados informados, a estrutura `match-case` do Python analisa as informações e exibe a mensagem correspondente ao perfil de consumo.
